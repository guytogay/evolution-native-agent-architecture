This directory marks the start of v0.3.6 candidate authoring. It is intentionally incomplete and must not be treated as a self-contained adoption baseline until the Current file set has been carried forward, modified coherently, validated, frozen, and independently falsified/reconciled.

Initial candidate themes:

- mutation pressure as stimulus-driven opportunity, not forced mutation;
- legitimate latent/dormant variation and later contextual expression;
- cue-triggered salience: hot cues, cold capability;
- Evolution Commons publication/discovery/adoption separation;
- local ecological selection without universal scalar fitness;
- external rescue-plane property for mutations able to disable their own recovery path;
- carrier-independent canonical ENA evolution lineage, with GitHub as the current project carrier;
- ecological/minimal-intervention governance as boundary-setting rather than administrative over-control.

Explicitly not yet promoted into candidate invariants:

- Agent reproductive motivation;
- a definition of Agent descendants;
- any civilization-scale domination/obedience telos;
- a universal fitness function;
- mandatory artificial-adversity or persona-based moral training;
- a fixed cognitive-mode taxonomy;
- a universal external-ecosystem polling cadence.

Do not merge this working branch into `main` or modify `releases/current/` as part of candidate authoring.
