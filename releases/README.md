# Releases

For adoption, there is exactly one active surface in this directory:

`current/`

Read `current/CURRENT-BASELINE.yaml` for the machine-readable ENA version and maturity/status, then use only the files under `current/` for effective behavior.

Do not infer the active ENA from version numbers, branch names, commit recency, candidates, or historical evidence.

Historical formal releases are indexed in `../HISTORY.md` and remain recoverable through immutable Git commits/trees and release evidence. Candidate histories remain in Git and collaboration evidence rather than appearing here as parallel adoption choices.
