# CONTRIBUTION PROTOCOL

All legitimate ENA participants may read project knowledge, research, critique, propose, experiment within existing authority, and contribute.

Recommended contribution classes:
`INCIDENT`, `NEAR_MISS`, `FRICTION`, `VALUE_OBSERVED`, `COUNTEREXAMPLE`, `PORTABILITY_FINDING`, `NEW_VARIATION`, `EVIDENCE_RESULT`, `RESEARCH_HYPOTHESIS`, `CRITIQUE`.

When possible include `ena_version`, package digest, relevant host/runtime/model/tool/route/configuration facts, relevant Active Governance Set states, event/outcome, ENA effect/friction, evidence refs, uncertainty, and alternative explanations.

Contribution does not grant reconciliation, promotion, Mainline, or unrelated implementation authority.
