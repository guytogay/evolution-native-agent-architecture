# Operational HOW Map — v0.3.8 Current

Status: `CURRENT / COLD_HOW_LIBRARY`

Each node is a property/problem family with plural possible implementations. A listed HOW is not automatically required; Host-native equivalents are allowed.

- **OA-RT-01 Runtime routing** — compact hot cues + cold retrieval; field evidence still required for natural future salience.
- **OA-MEM-01 Memory Metabolism** — compile/archive/retrieve rather than raw episode accumulation; memory is not authority or evidence truth.
- **OA-RET-01 Retrieval** — semantic search, exact lookup, scope registry, bounded no-hit/WAIT; one hit is not global completeness.
- **OA-PROJ-01 Projection** — preserve decision-material dependencies while compacting; summary validity is not material-use readiness.
- **OA-WAIT-01 WAIT** — callback/event/timer/bounded poll/manual wake; timeout is not replay permission.
- **OA-AUTH-01 Authority** — Host RBAC/capability/mandate/PDP/human delegation or `NOT_REQUIRED`; credential possession is not mandate truth.
- **OA-EFF-01 Effect Lifecycle** — idempotency/fencing/version check/provider query/workflow identity/compensation/WAIT; attempt, receipt and settlement differ.
- **OA-COM-01 Commitment/Settlement** — explicit obligation subject, executor, effect identity and settlement evidence; executor change does not silently transfer/erase obligation.
- **OA-REC-01 Recovery** — durable checkpoint, rescue path when material, restore drill, post-restore effect/authority reconciliation.
- **OA-ID-01 Continuity** — resolve continuity for the actual decision; continuity is not authority.
- **OA-AUTHOR-01 Contested Authorship** — attributable lineage for durable material self-surface change; ordinary cache/task state may be out of scope.
- **OA-STAND-01 Standing Input** — correction-bearing objection can matter without granting sovereignty/veto.
- **OA-EVID-01 Evidence** — provenance/support/applicability/dependency; schema-valid metadata is not evidence truth.
- **OA-EVO-01 Evolution** — latent variation, Variation Space, reality contact, local selection; source/popularity is not fitness.
- **OA-MIG-01 Migration/Commons** — packet/Git/registry/object-store/live protocol patterns; receiver performs local selection.
- **OA-ECO-01 Ecology** — control retirement, quotas/resources/reputation where applicable; no universal risk score or retirement age.
- **OA-ADOPT-01 Adoption** — singular Current, compact kernel, cold library, optional references, Host mappings, language projection, exact release identity.

Common compositions:

`Retrieval -> Projection`; `Authority -> Effect`; `Effect -> Recovery`; `Evidence -> Dependency`; `Evolution -> Packet -> Commons -> receiver selection`; `Runtime cue -> HOW -> Host adapter`.

Composition does not transfer evidence maturity between organs.
