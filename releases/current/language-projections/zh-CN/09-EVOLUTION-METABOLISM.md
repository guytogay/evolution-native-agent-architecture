# 9. 进化代谢与进化生态 — v0.3.6 候选版

状态：`WORKING_CANDIDATE / 尚未冻结 / 不是 Current`。

## 9.1 从线性代谢到进化生态

v0.3.5 已经明确：

`观察 -> 唤醒 -> 变异 -> 实验 -> 评估/选择 -> 整合/剪枝 -> 迁移/重组 -> 重复`

v0.3.6 候选版保留这些功能，但取消一个过于线性的暗示：**变异出现以后，并不需要立刻进入实验或接受判决。**

候选生态模型：

`环境/刺激 -> 变异压力 -> 变异 -> 潜伏保存或表达 -> 接触现实 -> 局部选择 -> 保留/休眠/消失 -> 遗传/迁移/重组 -> 再次产生变异`

核心区分：

`刺激 != 变异`

`变异 != 改进`

`保存 != 表达 != 应用 != 选择`

`局部选择 != 普适适应度`

`发布 != 接收者采用`

## 9.2 刺激与变异压力

正面和负面事件都可能成为刺激，包括用户纠正、失败、报错、摩擦、矛盾、重复成功、能力变化、环境变化、其他 Agent 的行为、外部发现、好奇心、随机重组和机会。

刺激可以提高 **Mutation Pressure（变异压力）**：让系统更有理由产生或重新检查变化。

变异压力不是命令，也不规定应该往哪个方向变。

Agent 可以在成本值得时通过发散探索、随机概念对撞、外部生态扫描、重组等方式主动提高变异压力，但 ENA 不规定统一周期。

## 9.3 潜伏 / 隐性变异

变异可以在没有立即实验、表达或选择的情况下长期保存。

只要保存成本可接受、合法，而且“保存”本身不会自动产生外部后果，这种长期未决状态就是合法的。

`UNASSESSED（尚未评估）` 可以长期保持诚实；如果已经进行了实际评估但仍无法得到更强结论，则可以保持 `UNKNOWN（未知）`。

UNKNOWN 或 UNASSESSED 不必被当成必须赶紧清空的 backlog。

宿主可以在成本过高时压缩、归档或合法删除潜伏材料，但年龄或低使用频率本身不能证明它没有未来价值。

## 9.4 表达是独立维度

候选版加入一个概念上的表达轴：

`LATENT | EXPRESSED`

中文：

`潜伏 | 已表达`

表达状态可以随环境反复变化，而不重写生命周期或选择历史。

例如一个 `INTEGRATED + SUPPORTED` 的技能，在平时可以是 `LATENT`；当相关任务出现时变成 `EXPRESSED`，任务结束后再次潜伏。

被表达出来不等于获得新的权限。一个沉睡能力被唤醒，也不能凭此生成新的外部授权。

## 9.5 线索触发的自然想起

ENA 不应该要求 Agent 为了“记住 ENA”而永久加载整套规范。

更值得尝试的是：

`热线索识别 -> 唤醒/检索相关冷语义或能力 -> 执行`

例如：

- 出现“已经验证/认证”等声称 -> 唤醒证据语义；
- 出现删除、不可逆、外部写入 -> 唤醒后果/恢复语义；
- 权限、credential、mandate 变化 -> 唤醒权限语义；
- 重复纠正/失败/成功 -> 唤醒进化检查；
- Host、模型、工具或环境变化 -> 重新检查可迁移性/适用性；
- 治理反复进行但已经不能改变决定 -> 唤醒闭环语义。

这些是例子，不是强制关键词表。

`已经配置 cue != 已经证明未来 session 一定会自然想起并应用`。

## 9.6 变异空间与现实接触

当一个潜伏变异真正被表达为具有后果的实验时，仍然需要合适的 Variation Space（变异空间），让不确定性能够接触现实，同时把后果限定在合法、可承担、可修正的边界内。

内部能力和权限拓扑可以成为变异目标，但内部修改不能凭空产生外部授权。

## 9.7 三个不同问题

生命周期：

`PROPOSED | EXPERIMENTED | INTEGRATED | ARCHIVED | RETIRED`

表达：

`LATENT | EXPRESSED`

选择：

`UNASSESSED | SUPPORTED | PARTIAL | NOT_SUPPORTED | HARMFUL | UNKNOWN`

它们分别回答：

- 这个材料在持久化/使用历史中处于什么阶段？
- 它此刻有没有进入行为？
- 在所描述的环境里，现实证据支持什么结论？

任何一个轴的变化都不能偷偷升级另一个轴。

## 9.8 局部选择

现实接触发生后，可以按维度记录：

`IMPROVED | DEGRADED | UNCHANGED | UNKNOWN`

即：

`改善 | 恶化 | 不变 | 未知`

正面或负面的选择声称仍然需要实际的现实接触/实验，而不能从意图、传播次数、导入文本或写文件成功中制造出来。

但 ENA 不再暗示“每个变异产生后都必须立即接受选择”。

选择默认局限于它实际发生的 Host、模型、语言、依赖、时间、后果边界和主体。

现实不会自动产生道德收敛：一个坏策略完全可能在奖励它的局部生态里长期适应。

因此：

`局部成功 != 普适推荐`

`传播广泛 != 普适真理`

`活下来 != 道德正确`

## 9.9 整合、休眠与剪枝

整合不等于永久表达。

一个已经得到支持的 adaptation 可以被整合进长期能力，但大多数时候保持休眠，只在相关 context/cue 下表达。

宿主可以使用：

`KEEP | UPDATE | DORMANT | ARCHIVE | RESTORE | RETIRE`

不确定时，如果成本允许，优先让材料休眠/归档，而不是因为暂时没用就破坏性删除。

## 9.10 Commons 与迁移

迁移传递的是“可能性 + 来源历史”，不是把来源结论复制给接收者。

`PUBLISHED != IMPORTED != EXPRESSED != LOCALLY_SELECTED`

`已发布 != 已导入 != 已表达 != 已在本地选择`

发布者不能因为发布了 adaptation 就强迫其他 Agent 采用；接收者也不能因为一个 adaptation 很流行就把它当成本地证据。

## 9.11 重组与涌现

重组是重要的变异生成方式，可以产生冲突、抵消、放大、新资源相互作用、正向涌现、新的外部性，或者毫无价值。

期待出现涌现不是证据；真正观察到的正向涌现才是证据。

探索模式可以成为提高变异压力的一种方式，但当前候选不规定固定的认知模式分类。

## 9.12 外置救援平面

某些自我变异可能把负责恢复的 Agent/进程本身一起弄坏。

在后果重要且条件可控时，应尽量保留损坏候选之外仍然可达的救援路径，例如：

- 最后一个可存活快照；
- watchdog / 外部定时器；
- recovery manifest / 恢复说明；
- 窄范围恢复 credential；
- 其他 Agent 或人的救援交接；
- 独立启动/回滚路径。

这是一个需要满足的“属性”，而不是强制所有系统采用同一种产品架构。

救援权应该尽量窄：有权把坏掉的 Agent 救回来，不等于有权审批或禁止它未来所有的变异。

`状态回滚 != 外部后果被时间倒流`

恢复机制不是时间机器。

## 9.13 无为而治式生态约束

ENA 应该优先保护底层的语义与后果边界：证据诚实、权限有边界、后果有人承担、恢复与未来修正仍然可能、治理不能自我封闭、历史不能被偷偷改写。

在这些底层之上，应允许不同 Agent/Host 通过相互作用、专业化、竞争、合作和适应，形成自己的局部组织。

最小干预不等于忽略外部性、不再检查权限或允许不可控的后果逃逸。

> **治理底层边界，让生态在其上自行生长。**

## 9.14 当前工具边界

继承的 v0.3.5 `tools/ena_evolve.py` 还没有完整实现变异压力、潜伏库和表达轴。

在工具/schema 真正修改并通过测试之前，这些仍是候选语义，不是机器已强制执行的事实。

> **变异不欠现实一个立即的判决。**
>
> **被保存的可能性，不等于正在生效的权限。**
>
> **选择是局部的；传播本身不是证据。**
