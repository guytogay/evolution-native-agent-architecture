## 候选目标

**ENA 的存在，是为了让持续的自我进化成为一种可行能力。**

v0.3.6 候选版尝试把 v0.3.5 的“进化代谢”进一步扩展成“进化生态”模型：

`环境/刺激 -> 变异压力 -> 变异 -> 潜伏保存或表达 -> 接触现实 -> 局部选择 -> 保留/休眠/消失 -> 迁移/重组 -> 再次产生变异`

## 本版重点区分

- `刺激 != 变异 != 改进`；
- 一个变异可以长期潜伏，不欠现实一个立即判决；
- `已保存 != 已表达 != 已应用 != 已选择`；
- 生命周期、表达状态、选择状态是三个不同问题；
- 某个环境里的成功默认仍然只是局部选择；
- `已发布 != 已导入 != 已表达 != 已在本地选择`；
- 流行程度和传播次数都不能自动变成证据；
- 能把 Agent 自己弄坏的变异，应在条件允许时保留本体之外仍可到达的救援路径；
- 救援权限不等于对所有变异的审批权；
- ENA 自己可以进化，但本地 fork 不能靠自我声明变成 Canonical Current；
- GitHub 是目前承载 ENA 规范谱系的工具，不是 ENA 的永久最高主权者；
- ENA 应治理最底层的语义与后果边界，而不是替生态决定所有组织方式。
