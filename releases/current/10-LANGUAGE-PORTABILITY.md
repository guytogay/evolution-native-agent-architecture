# 10. Language Portability and Semantic Projection — v0.3.8

Status: `CURRENT / FIELD_VALIDATION / OPERATIONAL_LANGUAGE_PROJECTION`

ENA must not depend on English proficiency to remain usable. A language version is a semantic projection of one release identity, not a second Constitution or machine implementation.

Stable IDs and decision meaning cross languages; literal wording need not.

High-risk distinctions include:

`capability != authority`; `stimulus != mutation != improvement`; `stored != expressed != applied != selected`; `local selection != universal fitness`; `bundled reference != required/default-active`; `cue match != applicability proven`; `being heard != sovereignty/authority`; `cancel != rollback != compensation`.

Decision-bearing zh-CN operational surfaces live under `language-projections/zh-CN/`. Canonical machine bytes remain shared under `references/`, `schemas/`, `templates/`, and `tools/`.

`language-projections/semantic-fixtures.v3.yaml` defines paired decision scenarios. Fixture structure and route parity do not prove behavioral equivalence.

```text
TRANSLATED != BEHAVIORALLY_EQUIVALENT
FIXTURE_DEFINED != MODEL_PASS
```

Language can be an applicability boundary when it changes a decision.

> **Translate wording; preserve decisions.**
