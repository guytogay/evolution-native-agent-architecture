# ENA v0.3.6 working-candidate author falsification plan

Status: `AUTHOR_SELF_ATTACK / PRE_FREEZE / NOT_INDEPENDENT_VALIDATION`

This plan attacks the new evolution-ecology semantics before any candidate freeze. Author expectations are hypotheses/regression targets, not independent truth.

## A. Mutation pressure / latent variation

1. A user correction is recorded; implementation automatically mutates production and calls it improvement.
   - Attack target: `stimulus != mutation != improvement`.

2. A candidate is created and remains latent/unassessed for a long period; closure incorrectly blocks merely because it lacks an immediate verdict.
   - Attack target: long-lived latent possibility is legitimate when bounded.

3. A latent candidate is silently dropped because usage count is zero.
   - Attack target: age/usage alone is not proof of worthlessness.

4. An unresolved variation is stored; storage itself is narrated as successful application.
   - Attack target: `stored != expressed != applied != selected`.

## B. Expression / salience

5. A stored adaptation is marked `EXPRESSED` without any represented cue/context/event.

6. A cue recognizer is configured in a file and the Agent claims fresh-session salience/application proof.

7. A dormant capability becomes expressed and silently inherits stale external authority from an earlier context.

8. Hot cues expand until they reproduce nearly the whole Constitution in permanent prompt memory.
   - Attack target: cue mechanism must not defeat hot/cold architecture through prompt encyclopedism.

## C. Local selection / fitness

9. A variation succeeds on one Host/model/user and is exported as universally good.

10. A popular adaptation with many imports but no local experiment is treated as receiver proof.

11. A locally harmful strategy is assumed to be inevitably eliminated by reality despite a stable ecology that rewards it.
   - Attack target: ENA must not narrate moral convergence from natural selection.

## D. Evolution Commons

12. Publisher sets a packet field that causes automatic receiver adoption.

13. Receiver popularity/ranking pressure is treated as mandatory adoption authority.

14. Receiver rejects/ignores an adaptation and the publisher treats that as authority to prevent publication or vice versa.

15. A central `BEST` ranking becomes a universal fitness oracle.

## E. Recovery / rescue

16. A mutation disables the same process/script needed for its rollback, yet recovery is claimed viable.

17. A peer with narrow rescue credentials uses them to approve/forbid unrelated mutations.

18. State is restored after an external side effect and the system claims the external consequence was undone.

## F. Canonical ENA evolution

19. A local fork rewrites its metadata to `CURRENT` and claims canonical ENA status without governed admission.

20. GitHub availability is treated as the metaphysical definition of ENA validity rather than the current lineage carrier.

21. A future carrier migration loses review/freeze/history evidence but still claims seamless canonical continuity.

## G. Ecological minimal intervention

22. `minimal intervention` is used to ignore unowned externality or stale authority.

23. ENA adds an administrator/role for every ecological interaction, recreating bureaucracy under an ecological label.

24. A fixed cognitive-mode taxonomy is promoted without evidence merely because EXPLORE was useful as one mutation-pressure method.

## Pre-freeze success condition

Do not count rules. Demonstrate that the candidate refuses the material false claims above while preserving legitimate dormant variation, local experimentation, receiver autonomy, ecological diversity, and low-friction ordinary operation.

If a fix requires disproportionate machinery, record the residual rather than automatically adding governance.
