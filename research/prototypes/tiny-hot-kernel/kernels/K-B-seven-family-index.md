# K-B — Seven-Family Advertised Index

Status: `RESEARCH_PROTOTYPE_CANDIDATE`

This candidate reuses the existing Current `CONSTITUTION-CONCEPT-MAP.yaml` family split as a compact always-loaded index.

```text
Retrieve ENA cold semantics when a MATERIAL decision touches:

E1 evolution-agency      — self-mutation, latent variation, correction pressure
A1 authority-power       — credential/capability/mandate/external authority
T1 evidence-truth        — claims, evidence, uncertainty, local-selection scope
R1 recovery-history      — rollback/restore/rescue/history/irreversible effect
D1 diversity-portability — Host/model/language/import/migration applicability
C1 composition-effects   — retry/parallelism/multi-Agent/shared effects/emergence
G1 governance-evolution  — new controls/processes, closure, externality, over-governance

On one or more matches:
-> invoke the ENA Semantic Router for exact Current targets.

On material uncertainty about whether a family applies:
-> retrieve/broaden rather than assume no match.

On cold retrieval failure:
-> do not claim ENA was successfully consulted;
-> use the route fallback proportionate to consequence.
```

## Hypothesis

Likely the strongest canonical traceability because family IDs are already present in Current and can be regenerated from the concept map.

## Main failure risks

- family labels are useful only after prior ENA familiarity;
- keyword/category matching replaces real decision-shape recognition;
- future additions tempt an O(N) hot catalog;
- false positives from lexical lookalikes such as `root`, `role`, or `model`.
