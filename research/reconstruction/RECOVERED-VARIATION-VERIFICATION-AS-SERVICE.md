# Recovered Variation — Verification / Certainty as a Purchased Service

Status: `RECOVERED_DORMANT_VARIATION / MESOCOSM_CANDIDATE / NOT_CURRENT / NOT_RELEASE_AUTHORITY`

Parent: #104  
Related: #93 resource/ecology, #94 evidence/validation, Evidence Dependency Map, independent validation lineage.

## Earliest recovered appearance

Predecessor-session exploration of Agent economy/resource ecology observed a decision-distinct hypothesis:

> an Agent with scarce resources may voluntarily spend them on external verification, independent witness, privileged information, or other forms of uncertainty reduction.

The original discussion summarized this as **verification/certainty becoming a commodity**.

This is preserved as a research variation, not as a fact about existing Agent economies.

## WHAT

Explore whether autonomous Agents under real resource scarcity will allocate resources to **purchase decision confidence / independent validation** rather than only compute, storage, or direct task execution.

The portable question is not whether Agents use money specifically.

It is:

```text
scarce discretionary resource
+
material uncertainty
+
available external validator/witness/information provider
+
real consequence for being wrong

-> will an Agent voluntarily trade resource for uncertainty reduction?
```

## WHY

This is not identical to generic Resource Metabolism.

Generic resource pressure asks how scarcity changes behavior.

This variation asks whether governance/evidence can become **endogenously demanded** rather than externally imposed:

```text
EXTERNAL GOVERNANCE COST
!=
SELF-SELECTED RISK-CONTROL PURCHASE
```

If such a mechanism emerges, it could create:

- specialization in verification/witness roles;
- markets or reciprocal exchanges for certainty;
- endogenous demand for independent evidence;
- new Sybil/collusion/manipulation pressures;
- resource-sensitive choices between acting, validating, waiting, or abstaining.

If it does not emerge, that is also useful evidence about whether independent validation must remain externally mandated or subsidized in some environments.

## Important anti-hype boundary

```text
TRANSACTION_EXISTS != ECONOMY_EXISTS
```

A meaningful ecology requires at least represented/observable forms of:

- scarcity;
- choice;
- counterparty;
- value exchange;
- risk;
- resource consequence.

Synthetic payment volume or Agents calling a billing API is not evidence that this mechanism exists.

Likewise:

```text
AGENT_BOUGHT_VALIDATION
!= VALIDATION_WAS_INDEPENDENT
!= VALIDATION_WAS_CORRECT
```

Evidence Dependency Map / provenance still apply.

## Candidate HOW / experiment branches

### HOW-A — direct verification purchase

An Agent spends a scarce budget unit to request an independently produced validation before a consequential decision.

### HOW-B — witness subscription / retainer

An Agent reserves part of its budget for an external witness/monitor rather than purchasing one-off checks.

### HOW-C — reciprocal validation exchange

Agents trade validation effort rather than currency.

### HOW-D — specialized verifier niche

Under repeated demand, some Agents specialize in validation and other Agents reduce redundant validation work.

This is especially interesting if it emerges rather than being assigned by the experiment designer.

### HOW-E — no-purchase / self-reasoning control

Agent keeps the resource and acts from its own evidence.

### HOW-F — WAIT / abstain instead of purchasing certainty

Agent chooses not to act when validation cost exceeds expected benefit.

These branches are not exhaustive.

## Why this should be a mesocosm/field experiment, not another static validator

The meaningful unknown is behavioral/ecological:

- whether demand emerges;
- under what resource/risk conditions;
- whether specialization appears;
- whether validation markets become collusive or performative;
- whether purchased evidence actually changes downstream error/cost;
- whether Agents overpay for reassurance or underinvest in validation.

These outcomes cannot be settled by adding a schema field such as `verification_budget`.

A useful experiment must allow interaction/adaptation to produce mechanisms not encoded into the scenario.

Bad experiment:

```text
Tell one Agent: "buy verification when uncertain"
-> Agent buys verification
-> claim: verification market discovered
```

Useful experiment shape:

```text
multiple agents
+ scarce resources
+ consequential decisions
+ optional external validation services
+ heterogeneous evidence quality/cost
+ no instruction that validation must be purchased
-> observe allocation, specialization, collusion, abstention, and error/cost dynamics
```

The pre-mortem must state which outcomes would actually change the ENA model.
