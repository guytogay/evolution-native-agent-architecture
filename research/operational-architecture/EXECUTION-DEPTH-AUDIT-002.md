## 2. Migration / Evolution Commons

### Repository reality

Current already separates:

```text
PUBLISH -> DISCOVER -> IMPORT -> EXPRESS/EXPERIMENT -> LOCALLY_SELECT
```

and explicitly says none of those arrows is automatic.

Current adaptation packet v2 plus reconstruction/projection/settlement work provides a portable semantic carrier and lineage boundary.

The remaining operational question is not one new packet field. It is the substrate used to publish/discover/import content and the protocol used for live Agent interaction.

### External HOW relatives

#### A2A

A2A Agent Cards expose Agent identity/endpoints/capabilities/skills; A2A Tasks/Messages/Artifacts provide active peer/task coordination.

Useful role:

`ACTIVE_AGENT_DISCOVERY_AND_TASK_EXCHANGE`

#### OCI Distribution

OCI Distribution is content-type agnostic and provides push, pull, content discovery and content management. Objects/manifests are digest-addressable and subject/referrer relationships can attach related content/provenance.

Useful role:

`DURABLE_CONTENT_ADDRESSED_COMMONS_SUBSTRATE`

#### Git / repository collaboration

Git repositories/issues/PRs already provide a slower but highly inspectable publish/discover/import surface with immutable commit/tree identities and human/Agent review workflows.

Useful role:

`INSPECTABLE_COLLABORATIVE_COMMONS_SUBSTRATE`

### Classification

`SEMANTIC_CARRIER_READY / COMMONS_SUBSTRATE_PATTERN_MISSING / ACTIVE_PROTOCOL_HOST_ADAPTER_REQUIRED`

### Result

Preserve these distinctions:

```text
ADAPTATION_PACKET
!= COMMONS_REGISTRY
!= AGENT_DISCOVERY
!= TASK_PROTOCOL

```

A new universal ENA wire protocol is not justified. A reusable substrate-pattern note is justified.

Therefore control retirement is not a missing WHAT/WHY.

### External HOW relatives

Feature-flag systems provide a useful mechanism analogy:

- distinguish live/deprecated/cleanup/archive/delete states;
- inspect recent use and dependencies before archive;
- remove code references/old paths before final archive/delete;
- retain archived history and allow restore;
- generate stale/cleanup events that can trigger automation.

This is analogy/mechanism transfer input, not proof that Agent governance controls are feature flags.

### Classification

`BOUNDED_PROCEDURE_JUSTIFIED / FIELD_EVIDENCE_REQUIRED / UNIVERSAL_THRESHOLD_NOT_JUSTIFIED`

A reusable Control Retirement procedure can now be authored without creating a universal control lifecycle schema.

