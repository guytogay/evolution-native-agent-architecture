## Assembly rules

1. Preserve plurality; do not collapse materially different HOWs.
2. Reuse before proliferating; compose existing organs before creating new ones.
3. Keep Host applicability explicit.
4. Keep evidence scoped.
5. Keep residuals/UNKNOWN/WAIT/dormancy visible.
6. Keep retired/failed HOW lineage recoverable.
7. Repository richness and active runtime context are separate problems.
8. Tiny Hot Kernel/routing should locate branches rather than contain the whole architecture.
9. Do not rewrite Current during assembly.
10. Route by consequence before ceremony.
11. A concrete HOW should say when it does not apply.
12. Distinguish missing link from missing organ.
13. Distinguish semantic carrier, durable Commons substrate, live Agent discovery/task protocol, and local adoption.
14. Control retirement must preserve the failure model and reactivation/lineage path where useful; quiet history is not retirement proof.
