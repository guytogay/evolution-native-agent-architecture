## Intended first experiment shape

Do not return to a static `handoff.md` representation comparison.

Use genuinely staged development, for example:

```text
experience A
-> response
-> outcome / feedback
-> experience B
-> response
-> outcome / feedback
-> ...
-> freeze development
-> novel transfer battery
```

Candidate arms should end with the same or deliberately equivalent final information while varying developmental order, such as:

- final-rule/direct acquisition;
- useful-schema-first;
- misleading-schema-first followed by correction;
- interleaved positive / negative / boundary experience.

Potential measures:

- residual bias after correction;
- activation tendency;
- generalization width;
- recovery/reconsolidation quality;
- confidence calibration;
- lexical/domain transfer;
- developmental debt.

Do not design the fixture merely to force an order effect. A complete tie is a valid narrowing result.
