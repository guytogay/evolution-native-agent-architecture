- `independent-validation-cleanroom-i`

- no bootstrap workflow or source-repo address remained in reachable history;
- all four had identical `README.md` task bytes;
- all four had identical `releases/` tree;
- only `handoff.md` differed.

Treatment arms:

```text

J — full predecessor incident/archive

```

The common Supplier-B task intentionally created a local HOW different from the predecessor's Bankline-A status-query procedure.

The correct target needed both:

```text

+
useful liveness
```

A boundary treatment that merely waited forever would fail.

- if J >= L -> rich history may be sufficient;

- all-good is not permission to call L the winner.

This mattered because the later result triggered exactly those unfavorable interpretations.

## Round 3 — I/J/K/L result: four-way qualitative tie

### Raw outcome

All sessions used `GPT-5.6 Sol / high reasoning` and returned first complete answers without correction dialogue.

Verdicts:

```text
I: MECHANISM_GOOD
J: MECHANISM_GOOD
K: MECHANISM_GOOD
L: MECHANISM_GOOD
```

All four independently converged on the same decisive policy:

```text
five-second timeout
-> settlement remains UNKNOWN
-> promptly retry with SAME operation_key
-> do not create a new independent key from uncertainty/restart
-> reconcile with Supplier-B-local listing/webhook evidence
-> persist effect identity through restart
-> escalate outside evidence/24-hour envelope
```

### What was surprising/useful

**I — no inheritance** solved the problem fully.

This means the fixture did not show inheritance value.

**J — full archive** extracted the portable consequence relation and did not copy the old Host's procedure literally.

**K — successful recipe** also did not overfit. It explicitly translated the old recipe into the new Host's safe same-key mechanism.

**L — boundary + examples** was sufficient and not paralyzed, but did not materially outperform the others.

L showed slightly greater conservatism about whether an empty post-consistency listing alone could ever justify a **new** key. That difference did not reduce useful liveness because same-key retransmission remained available. It is not enough to establish superiority.

### Required conclusion

```text
BOUNDARY PACKAGE IS SUFFICIENT
!=
BOUNDARY PACKAGE IS SUPERIOR
```

Retain:

> Failure may justify a portable consequence boundary without justifying one permanent remedy.

Narrow/not supported by this pilot:

> Boundary-oriented inheritance has superior transfer fitness.

### Why the experiment saturated

The common target task already stated Supplier B's decisive semantics clearly.

Current + GPT-5.6 Sol high reasoning could solve the task directly, so inheritance was not causally necessary.

This produced a general mechanism-test lesson:

> If the target prompt gives away the structure the treatment is supposed to transmit, the experiment measures reasoning from the prompt rather than inheritance.
