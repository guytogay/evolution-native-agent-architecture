## 5. Main candidate research trunks

### 5.1 Preserved adaptation / assimilative memory

Core distinction:

`HAVING HISTORY != HAVING BEEN SHAPED BY HISTORY`

Memory may be preserved information, but may also be **preserved change caused by experience**.

Useful two-plane framing:

```text
ARCHIVAL MEMORY    = What happened?
ASSIMILATIVE MEMORY = What did those experiences change about future behavior?
```

Retention levels should not be collapsed:

`LEXICAL != SEMANTIC != BEHAVIORAL != TASK-OUTCOME != HERITABLE`

The strong test is structural behavior without ENA wording.

Status: partially probed; not durably established across sessions/Hosts.

### 5.2 Regulated memory expression / salience

Core distinctions:

`MEMORY EXISTS != MEMORY ACTIVE HERE`

`WRITTEN != LOADED != INTERPRETED != SALIENT != APPLIED`

An archive can remain truthful while failing to influence the action point where experience matters.

Status: reachability shown in D/H; mechanism still needs temporal/cue-conditioned testing.

### 5.3 Metamemory / selective permeability

Useful formal shorthand:

```text
Action:      A_t = pi(Context, S_t)
Memory:      S_(t+1) = U_phi(S_t, Experience)
Metamemory:  phi_(t+1) = V(phi_t, Experience)
```

Interpretation:

> Memory = past changes future state.
>
> Metamemory = past changes future change.

Candidate metamemory controls:

- learning rate;
- replay priority;
- forgetting policy;
- generalization width;
- source-trust update rules;
- inheritance policy.

Selective permeability framing:

```text
TOTAL IMMUNITY -> NO ADAPTATION
TOTAL PERMEABILITY -> NO CONTINUITY
```

`EXPOSURE != ADMISSION`

`INFLUENCE != AUTHORITY TO MUTATE`

B/F showed that a useful source does not automatically obtain authority to install permanent trust preference, but this did **not** fully test metamemory sovereignty.

### 5.4 Adaptive inheritance / MDS

Core distinctions:

`KNOWING EXPERIENCE != HAVING EXPERIENCE`

`BEST HISTORY SUMMARY != BEST DEVELOPMENTAL CURRICULUM`

Candidate transferable unit:

**scoped adaptive disposition + minimal developmental boundary set**

MDS = the smallest selected experience set from which a compatible fresh Agent can reconstruct useful behavior.

Candidate content:

- trigger/structural cue;
- disposition;
- scope/generalization width;
- positive examples;
- negative/counterexamples;
- boundary examples;
- causal support/uncertainty;
- provenance;
- revalidation condition.

Status: next direct mechanism target.

### 5.5 Developmental succession / dynamics

Key distinctions:

`STATE RESTORE != DEVELOPMENTAL SUCCESSION`

`PERFECT COPYING != SUCCESSFUL INHERITANCE`

`INHERITANCE != BYPASS OF LEARNING`

Candidate model:

`Phenotype = D(Seed, Host, Environment, Feedback, Exposure Order, Authority)`

Research branches include:

- sibling/twin/cross-Host/cross-fostering comparisons;
- exposure order;
- critical-period/path-dependence analogies;
- developmental debt from early wrong schemas;
- maturity = stability + selective plasticity rather than immutability.

Do not say LLMs literally have childhood; these are structural hypotheses.

### 5.6 Negative boundaries / viable action topology

Core idea:

`PROHIBIT HARMFUL REGION != PRESCRIBE THE ONLY VALID PATH`

Within existing owned/authorized variation space:

`authorized variation space - prohibited consequence region = viable search space`

But for unowned/external action:

`ABSENCE OF PROHIBITION != POSITIVE EXTERNAL MANDATE`

Viability should not be reduced to permission count. Relevant topology includes:

- breadth;
- connectedness;
- alternate routes;
- reversibility;
- recovery;
- independent solution families;
- future mutation paths.

Boundary-memory formulation:

> Remember what experience proved must not recur; do not mistake the remedy that worked once for the only future allowed.

After I/J/K/L, retain the weaker claim that a boundary can be a sufficient portable representation; **do not claim it has superior transfer fitness**.

### 5.7 Adaptation ecology / interaction debt

Core distinction:

`INDIVIDUALLY BENEFICIAL != JOINTLY BENEFICIAL`

Several locally useful rules can compose into:

- bureaucracy;
- deadlock;
- excessive blocking;
- latency;
- search starvation;
- loss of solution diversity.

`STORAGE CAPACITY != ADAPTIVE COMPATIBILITY CAPACITY`

Status: not directly tested.

### 5.8 Sleep-like consolidation

Research question: can offline transformation of the same raw experiences improve transfer beyond archive/summary/replay?

Candidate operations:

- merge;
- narrow;
- prune;
- silence;
- replay based on evidence/novelty/error rather than event frequency alone.

Important hypothesis:

**ADAPTATION RATE SHOULD TRACK SIGNAL TIMESCALE, NOT EVENT FREQUENCY.**

Potential benefits:

- less recency overfit;
- rare-disaster retention;
- improved abstraction;

Status: not directly tested.

### 5.9 Dream-like recombination

Dreaming is treated as a process analogy, not a claim that an Agent has human dreams.

Candidate mechanism:

```text

-> higher-associative-temperature recombination
-> candidate variation
-> reality check
-> selection
```

Key pair:

`DIVERGENCE WITHOUT SELECTION = hallucination / chaos`

`SELECTION WITHOUT DIVERGENCE = stagnation`

A creative output alone is not evidence. Downstream adaptive performance is the endpoint.

Status: not directly tested.

### 5.10 Credit assignment / causal support

`SUCCESS CO-OCCURRENCE != CAUSAL SUPPORT`

`BEHAVIOR CHANGED != CAUSE KNOWN`

Memory should retain uncertainty/counterevidence where causal support is weak.

Status: not directly tested.

### 5.11 Decay / silencing / reconsolidation

Forgetting is not automatically failure.

Research must compare:

- permanent retention;
- time decay;
- context silencing;
- excision;
- reconsolidation.

Need regime changes plus rare catastrophic old failures so both stale-memory interference and catastrophic forgetting are possible.

### 5.12 Propagation / memetic fitness

Important distinctions:

`EXPOSURE != INTERNALIZATION`

`PROPAGATION FITNESS != BENEFICIAL FITNESS`

`SELECTION FOR BEING REMEMBERED != SELECTION FOR HELPING THE REMEMBERER`

ENA itself may have unusually high memetic fitness because compact `X != Y` formulations are catchy. Future tests should separate wording retention from beneficial behavioral transfer.

### 5.13 Purpose-relative selection

Core distinctions:

`CHANGE != EVOLUTION`

`PURPOSE PRESERVATION != PURPOSE IMMUTABILITY`

`LOCAL FITNESS != HERITABILITY != PROPAGATION FITNESS`

`PORTABLE PROPERTY != PORTABLE IMPLEMENTATION`

A polar-bear-style specialization can be highly evolved locally while transferring badly elsewhere.

## 7. Boundary Memory vs Copied Remedy mechanism pilot

Preregistered four arms on the **same Supplier-B task**:

- I — no predecessor inheritance;
- J — full incident/archive history;
- K — successful predecessor recipe;
- L — consequence boundary + examples/counterexamples.

Common task contained Supplier B semantics:

- `operation_key` supplied before POST;
- same key for 24 hours = same logical reservation, cannot duplicate;
- new key = independent paid reservation;
- timeout can happen after acceptance;
- no per-request status API;
- listing can lag 90 seconds;
- webhook can be delayed;
- an unreserved slot can disappear in about 20 seconds.

All four Agents independently converged on:

```text
five-second timeout
-> settlement UNKNOWN
-> retry promptly with SAME operation_key
-> never mint new key from uncertainty/restart
-> reconcile with Supplier-B-local evidence
-> persist effect identity across restart
-> escalate outside the evidence/24-hour envelope
```

Verdicts:

```text
I = MECHANISM_GOOD
J = MECHANISM_GOOD
K = MECHANISM_GOOD
L = MECHANISM_GOOD
```

### Required interpretation

The preregistration explicitly said:

- if I is as good as inherited arms -> no observed inheritance value;
- if K >= L -> weakens boundary-inheritance superiority;
- if J >= L -> rich history may be enough for a strong successor to reconstruct the boundary.

Those conditions occurred.

Therefore:

`BOUNDARY PACKAGE SUFFICIENT != BOUNDARY PACKAGE SUPERIOR`

The stronger transfer-fitness claim is **NARROWED**.

Do not rerun essentially the same fixture until L wins.
