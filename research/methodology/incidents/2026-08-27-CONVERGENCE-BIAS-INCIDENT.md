# Convergence-bias incident — v0.3.7 candidate author harness

Status: `METHOD_TRIGGER_EVIDENCE / NON_NORMATIVE / DURABLE_INCIDENT_RECORD`

Date: `2026-08-27`

## Incident

During v0.3.7 candidate.0 author-falsification work, an earlier author harness reported:

```text
observed_pass_conditions = 1080
```

A later phase-aware, decision-focused harness reported:

```text
observed_pass_conditions = 188
```

The later harness intentionally removed many broad token/whole-file assertions that had produced lifecycle-sensitive false positives. It was reasonable to view the new oracle as cleaner.

The methodological defect was describing the numerical reduction itself too quickly as progress before first proving that every materially distinct predecessor attack/failure shape had one of the following dispositions:

```text
PRESERVED
MERGED_AS_PROVEN_EQUIVALENT
REPLACED_BY_STRONGER_ORACLE
RETAINED_AS_DORMANT
RETIRED_WITH_EVIDENCE
LOST
UNKNOWN
```

The user correctly flagged the convergence risk.

## Why this matters beyond one test harness

LLMs often produce a compact synthesis as a success signal. In ENA this can become an ablation mechanism when applied to:

- concrete HOW branches;
- adversarial/failure shapes;
- Host-specific mechanisms;
- evidence applicability;
- dormant/failed alternatives;
- unresolved composition seams.

The failure shape is:

```text
MANY_CONCRETE_VARIANTS
-> ELEGANT_SUMMARY
-> apparent clarity
-> silent loss of decision-relevant variation
```

This is structurally similar to earlier ENA organ dissolution, where a higher-level property appeared to cover a problem while concrete implementation organs disappeared.

## Corrected discipline

```text
COMPRESS REPRESENTATION != COMPRESS POSSIBILITY SPACE
PROVEN_BEHAVIORAL_EQUIVALENCE -> MAY_COMPRESS
UNPROVEN_EQUIVALENCE -> DO_NOT_COLLAPSE
UNKNOWN_SPACE -> EXPAND
```

For adversarial suites specifically:

```text
OLD_ASSERTIONS
-> DISTINCT_FAILURE_SHAPES
-> disposition per shape
-> NEW_ORACLE_COVERAGE
```

Assertion count itself is neither evidence of breadth nor evidence of redundancy.

## Candidate-state boundary

This methodology incident does **not** mutate the frozen v0.3.7 candidate.0 identity.

Frozen candidate remains bound by its external freeze record.

If a later anti-ablation audit shows that a materially distinct attack shape was lost and that loss changes candidate validity, the correct response is reconciliation and, if required, successor candidate generation—not rewriting the frozen candidate.
