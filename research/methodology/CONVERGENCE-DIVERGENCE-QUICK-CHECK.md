# Convergence / Divergence Quick Check

Use this before any major ENA summary, consolidation, pruning, harness reduction, category merge, organ merge, or release-scope simplification.

```text
WHAT IS BEING REDUCED?
text / context / taxonomy / HOWs / failures / Host variants / evidence distinctions / active organs

ARE REMOVED ITEMS PROVEN BEHAVIORALLY EQUIVALENT?
YES -> compression may be valid
NO  -> preserve distinction
UNKNOWN -> preserve and investigate if decision-material

DOES ANY REMOVED DISTINCTION CHANGE:
action / validator verdict / authority / evidence / recovery / Host fit / failure / fallback / lifecycle?
YES -> do not collapse

IS THE SPACE STILL OPEN?
YES -> default toward discovery/divergence

IS THIS ONLY PRESENTATION?
YES -> summary is allowed only if full variation remains durably recoverable
```

Core reminder:

```text
COMPRESS REPRESENTATION != COMPRESS POSSIBILITY SPACE
```

For tests:

```text
FEWER_ASSERTIONS != BETTER_ORACLE
MORE_ASSERTIONS != BROADER_EVIDENCE
DISTINCT_FAILURE_SHAPE_COVERAGE is the relevant question
```

For HOW:

```text
SHARED_PARENT_PROPERTY != SAME_MECHANISM
```

For LLM summaries:

```text
ELEGANT_SYNTHESIS != SAFE_ABLATION
```
