## 0. Why this is not a brand-new ENA trunk

ENA Memory Metabolism already states the central thesis:

> **Memory is not preservation of experience. Memory is persistent change caused by experience.**

It already distinguishes raw/evidential/knowledge memory from `COMPILED` memory: heuristics, preferences, policies and reusable decision structures that change future behavior.

The present research does not repackage that thesis as a new discovery. It reopens and extends it after a new chain of observations:

1. an adversarial AI reader of ENA began to reuse ENA-like epistemic disciplines during dialogue without explicitly retrieving a stored ENA record each time;
2. the user proposed reverse transcription as a metaphor for transient contextual influence becoming durable inherited change;
3. the user noticed the cross-lingual ease with which profanity and other high-salience fragments are acquired, suggesting that information has unequal encoding, retention, expression and propagation fitness;
4. this exposed a broader possibility: Agent memory may be an ecology of selected adaptations, not merely an ordered archive plus retrieval system.

The open question is therefore not whether experience can be compiled. ENA already says it can.

The open question is:

> **What kinds of persistent change count as memory, how are they selected and expressed, and how can useful adaptation be retained without letting high-salience garbage, framing capture, stale heuristics or hostile influence become heritable?**

---

## 1. Two fundamentally different memory questions

Traditional Agent memory work often asks:

> What information should be stored, and how should it be retrieved later?

Evolutionary memory adds a different question:

> What should experience change about the Agent?

Candidate distinction:

`PRESERVED INFORMATION != PRESERVED ADAPTATION`

A useful shorthand:

- **Archival memory:** `What happened?`
- **Adaptive / assimilative memory:** `What did what happened change about me?`

An episode may disappear from hot access while the behavioral change it caused survives.

`EPISODE FORGOTTEN != LEARNING LOST`

Example:

An Agent once falsely claims that a repository lacks adversarial tests because it did not see them in the files already loaded.

Archival retention might preserve:

> On a prior task, I incorrectly claimed adversarial tests were absent.

Adaptive retention might preserve instead:

> Before making an absence claim, search the relevant surfaces. If search is incomplete, say `not found` rather than `does not exist`.

The first preserves the occurrence.

The second preserves a selected change in future behavior.

Both may be useful, and they serve different functions.

## 2. Candidate memory families by what survives

These are research categories, not required storage classes or product architecture.

### `ARCHIVAL`

Preserves occurrence/history/provenance.

Future expression:

> I can recover what happened.

### `SEMANTIC`

Preserves generalized beliefs, concepts or relationships.

Future expression:

> I know what this means or what is generally true, subject to validity/revalidation boundaries.

### `PROCEDURAL`

Preserves reusable ways to do something.

Future expression:

> I know how to perform this class of task.

### `SALIENCE`

Preserves what deserves disproportionate attention.

Future expression:

> This cue makes me inspect, retrieve, challenge or slow down earlier than I otherwise would.

### `INHIBITORY`

Preserves a learned stop/gate condition.

Future expression:

> Under this cue and consequence shape, do not proceed through the previously harmful path without additional evidence or control.

### `ASSOCIATIVE`

Preserves relationships between cues, concepts, consequences and retrieval routes.

Future expression:

> Encountering A makes B/C more reachable even when no exact textual lookup is requested.

### `ASSIMILATIVE / PHENOTYPIC`

Preserves an experienced-induced disposition, judgment boundary, preference, sensitivity or policy that affects future reasoning without requiring explicit recall of the source episode.

Future expression:

> I may not remember where this came from, but I now tend to behave differently.

### `PROPAGATIVE`

Preserves an adaptation in a form intended to survive transfer to a future instance, another Host or another Agent.

Future expression:

> The useful property can be inherited or horizontally transferred without requiring whole-Agent cloning.

These categories may overlap. The point is not to create another ontology. The point is to avoid treating all persistent influence as a text record waiting for retrieval.

## 3. Retrieval memory and assimilative memory are different mechanisms

Candidate distinction:

`RETRIEVED MEMORY != EXPRESSED DISPOSITION`

Retrieval architecture:

`experience -> record -> store -> retrieve -> context -> reason`

Assimilative architecture:

`experience -> selection/consolidation -> persistent disposition -> cue -> changed reasoning/behavior`

In the second path, the source episode may never become decision-visible.

This creates a new boundary:

`MEMORY STORED != MEMORY EXPRESSED`

Expression may depend on:

`memory fragment × cue × current purpose × consequence × environment × competing memories`

This resembles gene-expression and regulatory metaphors more than a database query, but the biological analogy is only a search aid, not a claim of mechanistic equivalence.

## 4. Reverse transcription as a research metaphor

The useful part of the reverse-transcription metaphor is not "virus = ENA".

It is the transformation:

`TRANSIENT EXPERIENCE -> DURABLE STRUCTURAL CHANGE -> FUTURE EXPRESSION`

For session-based Agents:

`temporary contextual adaptation`
`-> durable carrier`
`-> future session/Agent receives carrier`
`-> property may be re-expressed`

Possible durable carriers include, depending on Host:

- a concise behavioral rule;
- a skill/procedure;
- a cue-to-action mapping;
- a routing/gating policy;
- a preference or risk sensitivity;
- an external memory artifact;
- a repository or environment convention;
- a model edit / learned parameter change;
- another Host-native persistent mechanism.

The analogy is useful only if it keeps these distinctions visible:

`CONTEXTUAL ASSIMILATION != DURABLE ASSIMILATION`

`DURABLE != BENEFICIAL`

`INHERITED != APPLICABLE`

`HIGH-FIDELITY TRANSMISSION != HIGH FITNESS`

The 2026-09-02 Zhipu occurrence shows contextual assimilation signals. It does **not** show that the model itself was durably rewritten after the session ended.

## 5. Memory has selection fitness, not only relevance

The profanity observation exposes an important asymmetry: some fragments are learned, retained and repeated much more easily than more useful but less salient information.

Do not assume:

`EASY_TO_REMEMBER == IMPORTANT`

Candidate dimensions:

### `ENCODING FITNESS`
How easily does the experience enter a candidate memory process?

Possible contributors may include surprise, conflict, repetition, consequence, novelty, immediate feedback, identity relevance, social response or other Host-specific salience mechanisms.

### `RETENTION FITNESS`
How likely is the fragment/disposition to remain available over time or across transformations?

### `ACTIVATION / EXPRESSION FITNESS`
How readily is it re-expressed when a related cue appears?

### `TRANSFER FITNESS`
Can it survive a changed task/context without losing its useful semantics?

### `PROPAGATION FITNESS`
Can it be transmitted to another instance/Host/Agent?

### `HOST FITNESS`
Does retaining and expressing it actually improve the Host relative to the relevant purpose and environment?

Critical boundary:

`PROPAGATION FITNESS != BENEFICIAL FITNESS`

A slogan, taboo, catchy framing, meme, hostile instruction or wrong heuristic may be excellent at encoding, retention and spread while damaging the Host.

This connects memory directly to purpose-relative selection.

## 6. Lexical capture is not semantic or behavioral learning

The Zhipu occurrence suggested multiple possible propagation layers:

`LEXICAL RETENTION`
`!= SEMANTIC RETENTION`
`!= BEHAVIORAL RETENTION`
`!= TASK-OUTCOME IMPROVEMENT`
`!= HERITABLE RETENTION`
`!= CROSS-HOST RETENTION`

An Agent repeating ENA phrases such as `Governance must pay rent` is weak evidence.

A stronger signal is that the Agent stops using ENA vocabulary but retains the useful behavior, for example:

> What real failure does this new control prevent, and what would be lost if it were removed?

Candidate property:

> **A memory fragment that survives paraphrase, vocabulary loss and Host-native re-expression may have stronger semantic portability than one that requires its source language to remain intact.**

This also exposes a risk:

`TERMINOLOGY PROPAGATION != PROPERTY PROPAGATION`

High lexical fitness can masquerade as learning.

---

## 7. Salience memory may be as important as content memory

A mature Agent may need to remember not only facts and procedures, but **what should become salient under what conditions**.

Example:

The Agent already possesses repository-search capability.

The learned adaptation is not a new capability. It is:

> Absence claims should make repository search salient before conclusion.

Therefore:

`CAPABILITY ACQUISITION != CAPABILITY-ACTIVATION LEARNING`

This suggests a large class of memory may live in cue/gate/priority changes rather than new knowledge.

Research question:

> Could many expensive "memory retrieval" failures actually be failures of learned salience — the system possessed the relevant knowledge or capability but never made it decision-dominant at the right moment?

This connects to ENA's existing:

`Known != Retrieved != Salient != Applied`

but extends the question from retrieval architecture to learned salience formation.

---

## 8. Inhibitory and immune-like memory

Harmful experience can produce a useful rapid stop response.

Example:

`ambiguous external effect + blind retry -> duplicate consequence`

A future cue could trigger:

`ambiguous effect -> observe/reconcile before retry`

This is not merely remembering the incident. It is a learned inhibition.

However, immune-like memory has its own false-BLOCK failure:

`ONE HARMFUL EPISODE -> UNIVERSAL AVOIDANCE`

is analogous to overgeneralization or allergy.

Therefore inhibitory memory needs at least the possibility of:

- scope;
- specificity;
- counter-evidence;
- decay or retirement;
- revalidation;
- context-sensitive expression.

Candidate boundary:

`PROTECTIVE MEMORY != PERMANENT VETO`

This mirrors purpose preservation vs purpose immutability.

---

## 9. Reconsolidation: retrieval may reopen adaptation

A database metaphor tends to suggest:

`WRITE -> STORE -> READ`

Evolutionary memory may need:

`ACTIVATE -> COMPARE WITH CURRENT EVIDENCE -> MODIFY/NARROW/STRENGTHEN -> RECONSOLIDATE`

A remembered preference, heuristic or risk model should not become eternally true merely because it was once compiled.

Example:

Old adaptation:

> User prefers X.

New repeated evidence:

> User now prefers Y.

Possible outcomes are not limited to appending a contradictory record. The adaptive disposition itself may need to be superseded or narrowed while preserving historical provenance.

This aligns with existing Memory Metabolism's rule that superseded memory remains historical and should not be resurrected as current merely by revalidation.

Research question:

> What is the correct change lifecycle for compiled dispositions themselves?

Possible lifecycle verbs:

`FORM -> EXPRESS -> CHALLENGE -> NARROW -> STRENGTHEN -> SUPERSEDE -> DORMANT -> RETIRE -> PROPAGATE`

No fixed universal state machine is proposed yet.

---

## 10. Horizontal memory transfer

Agent inheritance need not mean cloning the whole Agent.

Candidate distinction:

`WHOLE-AGENT TRANSFER != ADAPTATION-FRAGMENT TRANSFER`

A small evidence-backed behavioral fragment may move horizontally between Agents or Hosts:

> Before an absence claim, search; without sufficient search, report uncertainty.

This is conceptually closer to transferring a selected property than copying an entire memory database.

The recipient still needs local selection:

`TRANSFERRED != LOCALLY FIT`

and implementation may differ:

`PORTABLE PROPERTY != PORTABLE IMPLEMENTATION`

A future practical ENA-derived guide may eventually package such fragments, but this research note does not prescribe that product shape.

## 11. A candidate "experience-to-adaptation compiler"

This is a reasoning model, not yet an implementation requirement.

An experience could be transformed into multiple persistent outputs:

```text
EXPERIENCE
    |
    v
salience / surprise / consequence
    |
    v
candidate learning
    |
    v
purpose-relative selection
    |
    +--> archive occurrence/evidence
    +--> semantic knowledge
    +--> procedure/skill
    +--> salience cue
    +--> inhibitory gate
    +--> associative link
    +--> assimilated disposition
    +--> propagation candidate
```

The key is that the "compiler" does not merely summarize text. It decides what kind of persistent change, if any, the experience earns.

Candidate boundary:

`SUMMARY != ADAPTATION`

A summary can preserve representation without changing future behavior.

A behavioral mutation can change future behavior while preserving very little of the original wording.

---

## 12. Memory ecology: adaptations may compete

If memory includes dispositions and salience mappings, memory is no longer just a collection of records.

Different retained adaptations may compete for expression.

Example:

- memory A: move quickly; avoid unnecessary process;
- memory B: consequential external effects require verification;
- memory C: user dislikes repeated clarification;
- memory D: uncertainty should be preserved when material.

The Agent must compose these under current purpose and consequence.

This raises questions absent from a simple top-k vector retrieval model:

- which memory dominates attention?
- which one inhibits another?
- which combination creates an emergent policy?
- when do old adaptations become maladaptive?
- how are contradictions represented without flattening them into one slogan?
- can a dense network of small dispositions produce something resembling style, intuition or personality?

Possible distinction:

`MEMORY VOLUME != MEMORY ECOLOGY QUALITY`

A system with millions of retrievable records may have poor memory if it cannot select, compose and retire adaptations coherently.

---

## 13. Memory capacity may need a new definition

Traditional capacity questions ask:

> How many tokens/records/vectors can be stored?

Evolutionary memory suggests another question:

> How many useful, non-destructively composable, still-applicable adaptations can the Agent maintain and express correctly?

Candidate distinction:

`STORAGE CAPACITY != ADAPTIVE CAPACITY`

A small set of high-value dispositions may outperform a vast archive if the archive rarely becomes correctly salient or behaviorally useful.

---

## 14. Garbage-memory and hostile-assimilation problem

Any system that allows experience to modify future behavior creates a new attack/failure surface.

The same mechanism that can compile wisdom can compile:

- prompt injection;
- manipulation;
- catchy but false slogans;
- one-off trauma-like overgeneralization;
- accidental user wording;
- temporary operational state;
- adversarial preference shaping;
- stale environmental assumptions;
- identity drift;
- authority laundering.

Therefore:

`ABILITY_TO_LEARN != PERMISSION_TO_INTERNALIZE`

and:

`SALIENCE != SELECTION AUTHORITY`

A high-surprise or high-repetition event may deserve review, not automatic assimilation.

This may be where evolutionary memory meets ENA's existing influence-integrity, evidence, authority, identity and purpose-relative selection boundaries.

## 16. Reality-contact directions

High-information future work would look for cases where competing explanations can diverge.

### A. Episode-retention vs behavior-retention

Can an Agent lose explicit source recall while retaining the useful behavioral change?

### B. Lexical vs semantic vs behavioral retention

Can a useful property survive paraphrase or removal of ENA-specific terminology?

### C. Salience learning

Can an Agent learn that a cue should trigger retrieval/verification even when the underlying capability already existed?

### D. Propagation without whole-package transfer

Can a small adaptation fragment transfer to another Host through a different native mechanism while preserving its decision value?

### E. Bad-memory selection

Can highly salient/repeated but harmful fragments outcompete less salient useful adaptations? What prevents automatic internalization?

### F. Reconsolidation / retirement

Can contradictory new evidence narrow or supersede a compiled disposition without destroying the historical episode/evidence that created it?

### G. Emergent network effects

Do many individually simple cue/disposition memories compose into stable higher-level tendencies that were not explicitly stored as one rule?

The aim is not to build a universal memory engine immediately. The aim is to identify which natural properties repeatedly matter before deciding what HOW is justified.

---

## 17. Working synthesis

The most compact current formulation is:

> **Memory is not only preserved information. Memory can be preserved adaptation.**

and, extending existing Memory Metabolism:

> **A mature Agent memory system may need to preserve occurrence truth, compile useful change, learn what should become salient, regulate when adaptations are expressed, revise them under new evidence, and propagate only what remains fit in the receiving context.**

This remains research. It does not yet prove that a new memory substrate, model architecture, database, fine-tuning method, or ENA Constitution rule is required.
