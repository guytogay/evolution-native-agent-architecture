# Purpose-Relative Selection and Propagation Fitness

Status: `RESEARCH_HYPOTHESIS / NATURAL-LAW CANDIDATE / NOT_CURRENT / NO_NEW_CONSTITUTION_ID_YET`

## Observation

ENA already distinguishes stimulus, mutation, and improvement, and already rejects universal transfer from local evidence. A further selection question is becoming clearer:

> A change should not be retained as evolution merely because something increased. Selection needs a purpose/environment relation, and propagation needs its own fitness question.

## Candidate natural-law structure

### 1. Change is not evolution

`CHANGE != EVOLUTION`

A mutation can increase speed, capability, complexity, automation, benchmark score, or local success while degrading what originally made the Agent useful.

The relevant question is purpose-relative:

> Relative to the purpose and selection context that made the adaptation valuable, which dimensions improved, degraded, remained unchanged, or remain unknown?

This extends rather than replaces ENA's existing multi-dimensional improvement discipline.

### 2. Purpose preservation is not purpose immutability

`PURPOSE PRESERVATION != PURPOSE IMMUTABILITY`

Selection should detect silent drift away from the purpose that justified an adaptation. It must not turn the original purpose into an eternal veto.

Distinguish:

- **purpose drift** — optimization changes behavior without an explicit re-evaluation of the purpose/selection context;
- **purpose evolution** — new evidence, environment, consequence, or legitimate decision explicitly changes the purpose or selection context.

The failure is silent drift, not all purpose change.

### 3. Local fitness is not propagation fitness

`LOCAL FITNESS != HERITABILITY != PROPAGATION FITNESS`

A locally successful adaptation may depend on one Host, model, tool, prompt, memory system, environment, credential topology, data source, or human support pattern.

Local success therefore does not prove that the adaptation:

- can be reliably inherited by a future instance;
- can transfer to another Host or Agent;
- retains value after its environmental dependencies change;
- deserves propagation into a shared commons or population.

### 4. Portable property is not portable implementation

`PORTABLE PROPERTY != PORTABLE IMPLEMENTATION`

A property may transfer while its concrete organ does not. Different Hosts may realize the same useful property through different native mechanisms.

Selection for propagation should therefore ask what is actually being propagated:

- a property;
- a concrete implementation;
- an evidence-backed pattern;
- a Host-specific specialization;
- or a dependency bundle whose usefulness disappears outside the source environment.

### 5. Portability is conditional, not a universal ranking

`MORE_PORTABLE != MORE_EVOLVED`

Specialization can be excellent evolution. Portability matters when migration, inheritance, reuse, commons propagation, or population-level spread is part of the objective.

Do not punish a useful local specialization merely because it is not universal.

## Selection dimensions exposed by this hypothesis

A mutation-selection decision may need to distinguish, where material:

- **purpose fit** — does the change improve the relevant purpose/outcome?
- **environment fit** — does it work in the actual local Host/context?
- **cost/tradeoff** — what useful capability, simplicity, resources, authority, or recoverability does it consume?
- **robustness** — does the value survive plausible local variation?
- **heritability** — can a future instance receive and correctly use it?
- **portability** — can the property or implementation transfer across relevant environments?
- **propagation value** — is spreading it useful to other Agents/Hosts/descendants?

These are not a universal checklist and do not have fixed weights. The selection subject and purpose determine which dimensions matter.

## Useful falsifiers / reality contact

Look for cases where:

1. a mutation improves an easy metric but degrades the purpose that justified the Agent;
2. an Agent explicitly changes purpose in response to new evidence and should not be classified as degraded merely for changing direction;
3. a locally excellent Host-specific adaptation fails to transfer but remains correctly selected locally;
4. the same portable property survives through a different Host-native implementation;
5. an apparently intrinsic Agent capability disappears when hidden environmental support is removed;
6. a highly portable adaptation spreads widely but is locally worse than a specialization.

The goal is not to prove that portability or purpose preservation is always good. The goal is to expose when each is a decision-relevant selection dimension.
