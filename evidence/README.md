# ENA Evidence

Status: `EVIDENCE_INDEX`

This area stores or indexes provenance-bearing observations used to test ENA claims. Evidence does not become normative architecture merely because it exists here.

## Evidence classes

ENA research distinguishes at least:

- `DESIGN_EXPECTATION`
- `CONTROLLED_TEST_EVIDENCE`
- `OPERATIONAL_USE_EVIDENCE`
- `REAL_INCIDENT_EVIDENCE`

Do not blur these grades.

## Subareas

- `reference-hosts/` — evidence from DSH and future ENA reference/adoption hosts.
- `historical/` — historical project fossils, prior agent incidents, external/adversarial artifacts, and related source evidence.

## Evidence discipline

Evidence should expose provenance, scope, limitations, observation interval/state where relevant, and claim boundaries.

A report about evidence is not automatically the source occurrence itself.

Valid evidence about one subject/state does not automatically support a different claim without justified applicability/revalidation.
